# گزارش موج ۹ — گیم هاب + مار بازی

## چه افزوده شد

### منطق خالص `src/lib/snake-logic.ts` (بدون DOM/تایمر — کاملاً قابل تست)
- `createGame(cols, rows)` — ساخت بازی با مار ۳‌تایی وسط تخته + غذای تصادفی روی سلول آزاد
- `step(state)` — یک تیک بازی: حرکت سر، رشد با خوردن، تشخیص برخورد با دیوار یا بدن (با در نظر گرفتن جابه‌جایی دم)
- `turn(state, dir)` — تغییر جهت با رد چرخش ۱۸۰ درجه
- `randomFood(snake, cols, rows)` — انتخاب سلول آزاد تصادفی (سنتی‌نال هنگام پر بودن تخته)
- `samePoint` / `onSnake` — ابزار مقایسه
- تست واحد: `src/lib/__tests__/snake-logic.test.ts` — **۱۱ تست پاس**

### هاب جدید `src/components/games-hub.tsx` (هاب «بازی»)
- ثبت در `HubProduct` (store) + `sync-routing` (`?hub=games`) + `app-shell` (لود لَـزی)
- کارت «بازی» در گاه‌وی هاب‌ها با آیکون `Gamepad2` و تن سبز جدید (`--hub-games`)
- **مار بازی**:
  - تختهٔ ۱۷×۱۷ رندر شده با گرید CSS، سر/بدن/غذا با افکت نوری و پالس غذا
  - تیک‌آپ سرعت‌گیر: هر امتیاز سرعت را کمی بالا می‌برد (حداقل ۸۰ms)
  - کنترل با کیبورد (جهت‌نما + WASD)، پد لمسی روی‌صفحه، دکمه‌های شروع/توقف/ادامه/شروع دوباره
  - اوورلی حالت‌ها: آماده / مکث / پایان بازی + پیام رکورد جدید
  - ذخیرهٔ بهترین امتیاز در `localStorage` (`jamino.snake.best`)
  - صف جهت تا دو حرکت (برای کلیدهای سریع)
- قفسهٔ «بازی‌های بیشتر» (۳ کارت به‌زودی: چیدمان پازل، بشّر دوره‌ای، کاوش میدان)

### ترجمه
- کلیدهای `hubs.games` / `hubs.gamesDesc` + بلوک کامل `games.*` در `fa.json` و `en.json`

### استایل
- `src/styles/games-hub.css` — قفسه‌بندی مار، تخته، پد، اسکوربورد، قفسهٔ به‌زودی، ریسپانسیو ≤900/≤640 و `prefers-reduced-motion`
- تن هاب `--hub-games` (سبز) در `hub-themes.css` + کارت در `music-production.css`

## چه تست شد
### خودکار
- `npx vitest run src/lib/__tests__/snake-logic.test.ts` — ۱۱/۱۱ پاس
- `npm run test` — ۱۵ فایل / ۱۵۸ تست همگی پاس

- `npm run build` — موفق (`Compiled successfully`)

### تأیید بصری زنده (مرورگر + Postgres موقت در Docker)
- Postgres موقت (`postgres:16-alpine`) راه‌اندازی شد، `prisma migrate deploy` + `db:seed` اجرا شد؛ `.env` موقتاً به Postgres اشاره کرد و پس از تأیید به حالت اصلی (`file:./prisma/dev.db`) برگشت
- ورود با کاربر `nava` موفق (۲۰۰)
- `?hub=games` → `hub-shell-games` رندر شد: تختهٔ ۱۷×۱۷ (۲۸۹ سلول)، غذا، ترجمهٔ «Game Hub»/«Snake»، ۳ کارت «به‌زودی»
- **جریان بازی کامل**:
  - Start → تیک بازی حرکت کرد (سر ۹→۱۴→۱۷ طی ۳ ثانیه)
  - کیبورد جهت‌نما + هر ۴ دکمهٔ پد لمسی جهت مار را عوض کردند
  - **خوردن غذا**: score ۰→۱ و طول مار ۳→۴
  - **Game over** با برخورد به دیوار → اوورلی + `Score: 1` + دکمهٔ «Play again»
  - **بهترین امتیاز**: در UI و `localStorage['jamino.snake.best']` ذخیره شد
- **RTL/فارسی**: `dir=rtl`، «هاب بازی»، «مار بازی»، «چیدمان پازل»، «همهٔ هاب‌ها» همه درست رندر شدند
- تأیید زندهٔ Render با VPN خارج از این موج است (جریان با DB محلی اثبات شد)

### باگ رفع‌شده در طول کار
- نمایش کلید خام `hubs.games` فقط به‌دلیل **HTTP cache کلاینت** بود: chunkهای `next dev` بدون هش نام دارند و مرورگر نسخهٔ کهنهٔ `app/layout.js`/`app/page.js` را نگه می‌داشت، در حالی که سرور bundle جدید (شامل `Game Hub`/`ARCADE`) سرو می‌کرد. با dev server روی پورت تازه (۳۱۱۱ → origin جدید = کش خالی) اثبات شد.

## چه باقی ماند
- بازی‌های بیشتر در قفسهٔ «به‌زودی» (پازل/پونگ/مین‌یاب) — پیاده‌سازی‌شان موج‌های بعدی است
- هماهنگی امتیاز آنلاین / چالش دوستانه بین کاربران (در صورت تمایل موج بعد)
- تأیید زندهٔ Render با VPN
- حذف کانتینر Postgres موقت `jamino-pg` (پورت ۵۴۳۲) در صورت عدم نیاز

## گام بعد
- در صورت درخواست: بازی دوم (مثلاً «بشّر دوره‌ای») یا چالش امتیاز بین دوستان (تختهٔ امتیاز در هاب).

## واژه‌نامهٔ موج
| واژه | معنی |
|---|---|
| تیک (tick) | یک گام حرکت بازی در بازهٔ زمانی ثابت |
| صف جهت (dir queue) | نگهداری ۲ جهت آخر برای پاسخ سریع به کلیدها |
| سلول آزاد (free cell) | خانه‌ای از تخته که مار روی آن نیست |
| اوورلی حالت | لایهٔ شیشه‌ای وسط بازی برای شروع/مکث/پایان |
