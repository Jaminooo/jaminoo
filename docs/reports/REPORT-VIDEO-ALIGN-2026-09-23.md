# REPORT-VIDEO-ALIGN-2026-09-23

موج: «هاب ویدیو هماهنگ با سینما/انیمه» — تکمیل چهارمین هاب تماشا با الگوی موج قبلی.

## چه افزوده شد

1. **دمو seed برای هاب ویدیو** — `ensureDemoVideo()` در `server.js` (الگوی `ensureDemoEntertainment`): وقتی جدول `VideoPost` خالی است، کانال دموی «Jamino Studio» ساخته می‌شود (کاربر `jamino_studio` فقط در صورت نبودن + درخواست کریتور APPROVED برای hub=VIDEO تا در قفسهٔ Creators هم ظاهر شود) و ۶ پست seed می‌شود: ۲ ویدیوی بلند (LONG)، ۲ شورت (SHORT)، ۱ پست ویدیویی و ۱ پست متنی خوش‌آمد — همه `PUBLIC/PUBLISHED` با فایل‌های Google Sample Bucket (همان منابع پایدار سینما/انیمه). فقط روی جدول خالی اجرا می‌شود؛ دادهٔ کاربر/ادمین دست نمی‌خورد.
2. **تکمیل i18n ویدیوهاب** — رشته‌های انگلیسی باقی‌مانده به کلیدهای از-قبل-موجود منتقل شدند: عنوان دکمه‌های Like/Comments/Save/Share/Save to playlist/Report (`video.common.*`)، حالت‌های خالی فید (جستجو/لیست تماشا/دنبال‌شده‌ها/فید — `video.feed.*` که از قبل ترجمه شده بود ولی استفاده نمی‌شد)، «You are all caught up» (`video.feed.caughtUp`)، و مودال پست (`video.common.postKicker`/`postFallback`/`close`). یک کلید جدید `video.toast.linkCopiedAt` برای توست اشتراک‌گذاری با timestamp در fa/en اضافه شد. بلوک empty state به JSX چندخطی خوانا شکسته شد.
3. **کتابخانهٔ فرمت ویدیو + جلد گرادیانی** — `src/lib/video-format.ts` (منطق خالص): `titleHue` (الگوریتم یکسان با سینما برای گرادیانِ پایدار و طراحی‌شده)، `coverGradient` و `durationLabel` (انتقال یافته از فایل هاب). در ویدیوهاب استفاده شد: بلوک «ویدیو در دسترس نیست» و نگارهٔ آیتم‌های پلی‌لیستِ بدون جلد، پس‌زمینهٔ گرادیانی گرم می‌گیرند — هم‌زبان بصری با هاب سینما. تابع `durationLabel` محلی حذف شد.

## چه تست شد

- ۹ تست unit جدید در `src/lib/__tests__/video-format.test.ts` (محدوده/تعینی بودن `titleHue`، شکل `coverGradient`، قالب‌های `durationLabel` شامل ساعت و مقدار صفر/منفی).
- کل سویت: **۹۵/۹۵ پاس** (`npm run test`).
- `npx tsc --noEmit` → صفر خطا.
- `npm run build` → موفق (فقط وارنینگ‌های از قبل موجود؛ هیچ وارنینگ جدیدی اضافه نشد).
- `node --check server.js` → موفق.
- JSON هر دو دیکشنری ترجمه معتبر است.

## چه باقی ماند

- تأیید زندهٔ Render (وقتی VPN روشن شد): باز کردن ویدیوهاب روی DB تازه/خالی و دیدن کانال دمو + پخش شورت/بلند، امتحان جستجوی فید (پاک‌شدن empty state فارسی)، و اجرای `queuetest.js` برای عدم رگرسیون روم موسیقی.
- جستجوی ویدیو هنوز به جستجوی سراسری ⌘K اضافه نشده (که عمداً در موج بعدی است — کاربر موج جستجوی سراسری را جداگانه انتخاب نکرد).
- `Get /api/video/posts?q=` جستجوی سروری دارد (عنوان/توضیح/@username)؛ هیوریستیک جستجوی بیشتر (مثل #topic) نیست — خارج از حوصلهٔ این موج.

## گام بعد

1. تأیید زندهٔ سه‌گانه وقتی VPN فعال شد (ویدیوهاب دمو + جستجو + queuetest).
2. موج بعدی (پیشنهادی): جستجوی سراسری ⌘K برای video/anime/groups/tweets — حالا که ویدیوهاب کامل شد، افزودن پست‌های ویدیویی به نتایج ⌘K ساده است (`GET /api/video/posts?q=`).

## واژه‌نامهٔ موج (Glossary)

| اصطلاح | معنی |
|---|---|
| `ensureDemoVideo` | سید بوتِ ویدیو فقط روی جدول خالی: کانال دمو + ۶ پست + درخواست کریتور APPROVED |
| `jamino_studio` | کاربر/کریتور دموی رسمی ویدیوهاب (قابل لاگین نیست، فقط محتوای نمایشی) |
| `titleHue` / `coverGradient` | گرادیان جلدِ پایدار از روی عنوان — الگوریتم مشترک با هاب سینما در `src/lib/video-format.ts` |
| `durationLabel` | قالب ساعت `h:mm:ss` / `m:ss` — حالا در کتابخانهٔ مشترک و تست‌شده |
| `video.toast.linkCopiedAt` | کلید ترجمهٔ جدید برای «لینک کپی شد — از همان لحظه شروع می‌شود» |
