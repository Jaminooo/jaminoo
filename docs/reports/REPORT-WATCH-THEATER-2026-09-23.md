# گزارش موج ۶ — Watch Theater (سالن تماشای اختصاصی)

تاریخ: ۲۰۲۶-۰۹-۲۳ ‏| وضعیت: تکمیل‌شده ✔

## چه افزوده شد

### صفحهٔ تماشای اختصاصی `/watch/[source]/[id]`
- روت داینامیک `src/app/watch/[source]/[id]/page.tsx` (سرویس‌ساید + `WatchPageView` کلاینت)
- پلیر بزرگ اختصاصی `VinylPlayer` با واریانت `feature`، دکمهٔ بازگشت، هدر با برند و `TopRightControls`
- برای **فیلم/سینما**: انتخاب کیفیت (Auto / 720p / 1080p / 4K) که به‌عنوان `?q=` به صفحه پاس داده می‌شود
- برای **سریال/انیمه**: تب فصل‌ها + لیست اپیزودها؛ هر اپیزود همان‌جا در پلیر بزرگ پخش می‌شود
- ریل **انیمه‌های مرتبط** (فقط anime — فیلم‌ها حذف می‌شوند) بر پایهٔ اشتراک ژانر
- ریسپانسیو کامل (گرید ۲ ستونه → یک ستون در موبایل) + RTL/LTR
- گارد خطا + حالت لودینگ + fallback تصویر/ویدیو دیفالت

### منطق خالص جدید `src/lib/watch-select.ts`
- `episodePlayUrl` / `titlePlayUrl` — fallback به `/defaults/videos/demo.mp4`
- `groupEpisodesBySeason` — دسته‌بندی اپیزودها به فصل‌ها (مرتب‌سازی عددی)
- `relatedTitles` — عنوان‌های مرتبط: فقط anime، بدون فیلم، رتبه‌بندی با اشتراک ژانر سپس امتیاز
- ثابت‌های `WATCH_QUALITIES` / `DEFAULT_QUALITY`
- **۱۱ تست واحد** در `src/lib/__tests__/watch-select.test.ts`

### API جدید
- `GET /api/cinema/[id]` — جزئیات یک عنوان سینما برای صفحهٔ تماشا (با rate limit ضمنی از `handle`)

### اتصال به هاب (watch-hub.tsx)
- دکمهٔ اصلی «Open theater / باز کردن سالن تماشا» در مودال جزئیات (انیمه و سینما)
- دکمهٔ «Preview / پیش‌نمایش» برای پخش سریع همان‌جا (پلیر همیشه‌نمای موج قبل حفظ شد)
- انتخاب کیفیت inline برای عناوین سینمایی داخل مودال
- دکمهٔ اپیزودها → باز شدن سالن با آن اپیزود مشخص (`?e=id`)

### ترجمه
- بلاک `watchPage.*` در `fa.json` و `en.json` + کلیدهای `watch.theater` / `watch.preview` / `watch.watchEpisode`

## چه تست شد
- `npx tsc --noEmit` — صفر خطا
- `npm run test` — ۱۳۳/۱۳۳ (۱۱ تست جدید watch-select)
- `npm run build` — موفق؛ روت `/watch/[source]/[id]` به‌عنوان dynamic ثبت شد

## چه باقی ماند
- موج ۷: بازطراحی هاب (هیرو + مگامنو، اسلایدر ژانر در بالا، دسته‌بندی فیلم/انیمه/کارتون)
- موج ۸: فصل‌ها در مدل داده، سید «Spanish / German / Brand New Day»، آپلود اپیزود در پنل ادمین
- تأیید زندهٔ Render با `queuetest.js` (نیاز VPN)

## گام بعد
شروع موج ۷ — اسلایدر ژانر در بالای صفحهٔ هاب + دسته‌بندی‌ها + هیرو با مگامنو.
