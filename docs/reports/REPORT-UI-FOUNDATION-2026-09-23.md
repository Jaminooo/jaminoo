# گزارش موج پایه‌ی طراحی فرانت‌اند — ۲۰۲۶-۰۹-۲۳

## چه افزوده شد

- وابستگی و importهای `framer-motion` به `motion` / `motion/react` منتقل شد.
- `MotionConfig` در ریشه‌ی برنامه تنظیم شد تا ترجیح کاهش حرکت سیستم رعایت شود.
- پالت مشترک بنفش، ایندیگو و فیروزه‌ای با شدت ملایم، سطوح شیشه‌ای، نورهای محیطی و گرادینت‌های آرام اضافه شد.
- گرادینت‌ها برای هاب‌ها، جامعه، لندینگ، احراز هویت، صفحه‌ی تماشا و پنل ادمین پوشش داده شدند.
- افکت Spotlight دنبال‌کننده‌ی نشانگر به کارت‌های صفحه‌ی انتخاب هاب و کارت‌های شاخص لندینگ افزوده شد.
- رنگ دکمه‌ی اصلی و دکمه‌ی Play پلیر از سبز قبلی به گرادینت هماهنگ جدید تغییر کرد.
- هیچ endpoint، schema یا منطق بک‌اندی تغییر نکرد.

## چه بررسی شد

- `npx tsc --noEmit` — موفق.
- `npm run build` — موفق؛ build گزارش خطا نداد و چند هشدار lint قدیمی در فایل‌های نامرتبط چاپ شد.
- `npm test` اجرا نشد.
- بازبینی بصری زنده در Chrome انجام نشد؛ runtime مرورگر در ابزارهای این نشست در دسترس نبود.

## چه باقی مانده

- بازطراحی جزئی هر بخش، از جمله وضعیت‌های خالی/بارگذاری، فرم‌ها، فهرست‌ها و صفحات موبایل.
- بازبینی و ارتقای تجربه‌ی پلیر ویدیویی و موزیک در خود صفحه‌ها.
- تکمیل طراحی تعاملی و ریسپانسیو پنل ادمین و جامعه.
- بازبینی بصری در مرورگر پس از در دسترس بودن اتصال مرورگر.

## گام بعد

- موج بعدی روی پلیرهای موزیک/ویدیو و قاب‌های اصلی هاب‌ها، بدون تغییر API یا داده‌ها.

## واژه‌نامه

- **Glass:** سطح نیمه‌شفاف با محوشدگی پس‌زمینه و خط دور روشن.
- **Aurora gradient:** نور گرادینتی کم‌اشباع که آهسته حرکت می‌کند.
- **Spotlight:** هاله‌ی ظریف روی کارت که موقعیت نشانگر را دنبال می‌کند.
