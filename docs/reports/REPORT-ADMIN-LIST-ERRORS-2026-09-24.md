# گزارش موج بازیابی فهرست‌های ادمین — ۲۰۲۶-۰۹-۲۴

## چه افزوده شد
- hook مشترک `useAdminList` دیگر خطای API را بی‌صدا رد نمی‌کند؛ پیام خطای ترجمه‌شده نشان داده می‌شود.
- داده‌های آخرین بارگذاری موفق حفظ می‌شوند و در درخواست ناموفق به شکل جدول خالی نمایش داده نمی‌شوند.
- این اصلاح به فهرست‌های کاربران، جم‌ها، پیام‌ها، گزارش‌ها، مدیا، درخواست‌های سازنده، نشست‌ها و کاتالوگ موسیقی اعمال می‌شود.

## چه بررسی شد
- `npx tsc --noEmit` موفق بود.
- `git diff --check` موفق بود.
- ریشهٔ سایت لوکال HTTP 200 برگرداند.

## چه باقی ماند
- تست خودکار، build و بررسی بصری Chrome انجام نشد؛ سرور dev برای پیش‌نمایش روشن است.
- بازبینی بخش‌های باقی‌ماندهٔ پنل ویدیویی ادمین ادامه دارد.

## گام بعد
- مرور جزئیات مدیریت موسیقی/ویدیو و بهبود بازیابی در مودال‌های فهرست.

## واژه‌نامه
- **hook فهرست:** منطق مشترک دریافت، جست‌وجو و صفحه‌بندی داده‌های مدیریت.
- **حفظ داده:** نگه‌داشتن نتیجهٔ قبلی وقتی درخواست تازه شکست می‌خورد.
