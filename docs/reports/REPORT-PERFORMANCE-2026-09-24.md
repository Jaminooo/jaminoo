# گزارش موج: سبک‌سازی اجرای رابط

## چه تغییر کرد

- صحنه‌های اصلی اپ به بارگذاری تنبل منتقل شدند تا کد هاب‌هایی که کاربر انتخاب نکرده وارد بار اولیه نشود.
- حلقه فریم تحلیل صوت وقتی پخش متوقف است یا تب پس‌زمینه است متوقف می‌شود.
- رندر سه‌بعدی تا وقتی صحنه دیده و موسیقی در حال پخش نباشد حلقه فریم نمی‌سازد.
- موج‌نمای دوبعدی هنگام توقف پخش حلقه رسم را متوقف می‌کند.
- صفحه تماشا دیگر برای نمایش پلیر منتظر دریافت کل فهرست فیلم‌ها و انیمه‌ها نمی‌ماند؛ پیشنهادها نزدیک بخش مرتبط و هنگام اسکرول بارگیری می‌شوند.
- صفحه‌های عمومی پروفایل و لحظه، متن‌ها و جهت چیدمان فارسی/انگلیسی را رعایت می‌کنند و درخواست قدیمی پس از تعویض مسیر دیگر state را بازنویسی نمی‌کند.

## چه بررسی شد

- `npx tsc --noEmit` بدون خطا
- `git diff --check` بدون خطا
- JSON پیام‌های فارسی و انگلیسی معتبر است.
- صفحه‌های خانه، پروفایل عمومی، لحظه و Watch روی سرور محلی پاسخ ۲۰۰ دادند.

## چه باقی مانده

- در این نشست اتصال Chrome پروژه برای اندازه‌گیری FPS، زمان پاسخ تعامل و بررسی تصویری مسیرها در دسترس نبود؛ بنابراین بهبود عددی ادعا نمی‌شود.
- مرور تک‌به‌تک مسیرهای عمومی، حساب، پنل مدیریت، Hubها و حالت موبایل هنوز ادامه دارد.

## گام بعد

- مرور routeهای مستقل و حالت‌های بارگذاری/خطا، سپس بازبینی موبایل و جمع‌بندی نهایی پس از تکمیل پوشش.
